# How atw-snoop works

## Two outputs at once

The Mega STE's shifter shows ST RAM; the ATW800/2 shows its own video memory on its HDMI output.
Neither waits for the other, so a program can keep its own screen and still have a second one.
atw-snoop gives that second screen to debugging.

## The grid in shared memory

The card's memory is visible to the 68000 on the VME bus (card base + $1F4000 is the window the
T425 also sees, at $807F4000). At +$400 in that window lies a text grid: one word per cell,
`character << 8 | attribute`, the attribute `ink | paper << 4` (16 colours). The 68000 only writes
these words: no commands, no handshake, no waiting.

On the card, a T425 transputer runs a small program (generated by `t425/build_snoop.py`, sent over
the card's link at start-up together with the font): it compares the grid with its own copy, again
and again, and draws every cell that changed in an 8×16 Terminus font. Each pass is paced by the
T425's timer (default about 20 ms): an unpaced T425 kept the card's memory busy and slowed the
68000's VME writes. Before each pass the T425 reads 64 KB elsewhere, because it caches its own RAM
and would otherwise keep seeing the grid as it was.

A pass counter in shared memory acts as a heartbeat: `snoop_frame()` checks it every 50 calls, and
if it stands still the library stops the T425 and lets the 68000 draw instead.

## Slots

Formatting numbers is what costs the 68000 time, not the bus. A slot moves the formatting to the
card. After the grid, shared memory holds a table of up to 128 slots of 16 bytes, written
big-endian by the 68000:

| Offset | Size | Content |
|---|---|---|
| +0 | long | the value |
| +4 | byte | kind: 1 hex, 2 decimal, 3 bar, 4 bytes as hex |
| +5 | byte | attribute |
| +6 | byte | digits, field width, bar width in cells, or byte count |
| +7 | byte | generation: changed when the slot is (re)defined or its cells were overwritten |
| +8 | word | the first cell's byte offset in the grid |
| +12 | long | a bar's maximum; for decimals a scale in thousandths (0: none) |

A 32-byte data area per slot follows the table (for kind 4). Each pass, the T425 formats every slot
whose value, generation or data changed into its cells, and the grid scan draws them like any other
cell. `snoop_set(id, v)` is a macro: one long write into the table.

A scaled decimal shows `value × max / 1000`: with `max = 26042`, raw clock counts appear as
microseconds, so the 68000 never multiplies or divides for the display.

## Finding the card

- Under plain TOS (the intended and tested way) the card is found by its id, see below. With the card's
  xVDI driver running (only an earlier version tried that), the desktop's screen address is the card's: atw-snoop borrows that
  page (256 colours, grid up to 100×40, LUT entries 240–255 borrowed and given back). The desktop
  redraws itself when the program ends.
- Without xVDI the card is found by its id at $A00000 or $C00000 (each probe guarded against a bus
  error); the library then programs 640×480 itself (grid 80×30) and switches the output off at the
  end.
- Whatever of the shared memory the grid and slots use is saved at start and written back at the end.

## The clock

`snoop_clock()` reads the 200 Hz system tick count and MFP timer C's counter: 192 counts per tick,
38400 per second, 26.04 µs per count. When timer C has run out but its interrupt has not been taken
yet (interrupts held off), the counter has restarted while the tick count is one behind; the clock
checks timer C's pending bit and adds the missing tick, so it never goes backwards.

The video address counter is no substitute: it stops at the screen's last line.

## Cost without a card

Every call returns at once when `snoop_mode` is 0. Guarding a block of per-frame calls with
`if (snoop_mode)` brings the cost on a machine without the card down to one test a frame.

## Memory

The grid's limits (`SNOOP_COLS_MAX` × `SNOOP_ROWS_MAX`, default 100×40) cost 4 bytes a cell of ST RAM
(a copy of the shared memory the grid borrows and the 68000 mode's copy of the screen): 17 KB with
the defaults.
